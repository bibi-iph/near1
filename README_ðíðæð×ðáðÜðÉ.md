# Near — сборка настоящего приложения (Android, с браслетом и точной геолокацией)

Эта папка превращает Near в **настоящее приложение** на телефоне, которое читает **фитнес-браслет / часы** (через Health Connect) и даёт **точную геолокацию**.

## Что уже настроено в проекте
- **Точная геопозиция** — через нативный плагин Capacitor (высокая точность GPS, запрос разрешения на телефоне).
- **Фитнес-браслет** — плагин `capacitor-health` (Health Connect на Android, Apple Health на iPhone): шаги и пульс.
- Сборочный файл `codemagic.yaml` **сам** добавляет все нужные разрешения Health Connect и минимум Android 8 — вручную ничего править не надо.

> Честно про первую сборку: я прописала всё по документации плагина, но не могу запустить билд из своей среды. Поэтому если первая сборка выдаст ошибку — **пришлите мне текст из лога Codemagic**, и я сразу поправлю. Так работает нормальная разработка: 1–2 прогона, и готово.

## Как собрать `.apk` без своего компьютера (облако, бесплатно)

### 1. GitHub — загрузить проект
1. Зарегистрируйтесь на **github.com**.
2. **New repository** → имя `near-app` → **Create repository**.
3. **Add file → Upload files** → перетащите **всё содержимое папки `near-native`** (файлы `package.json`, `capacitor.config.json`, `codemagic.yaml` и папку `www`) → **Commit changes**.

### 2. Codemagic — запустить сборку
1. На **codemagic.io** войдите через GitHub.
2. **Add application** → выберите репозиторий `near-app` (Codemagic сам найдёт `codemagic.yaml`).
3. Запустите workflow **«Near Android (debug APK)»** → **Start new build**.
4. Через 5–15 минут на почту **hhzzzd@seznam.cz** придёт **`.apk`** (и он же в разделе Artifacts на странице сборки).

### 3. Установить и включить браслет
1. Скачайте `.apk` на Android-телефон, откройте, разрешите установку из этого источника.
2. На телефоне должно стоять приложение **Health Connect** (на новых Android встроено; иначе бесплатно из Google Play), а браслет — привязан к своему приложению (Mi Fitness, Zepp, Fitbit, Samsung Health…). Тогда его данные попадают в Health Connect.
3. В Near: войдите как пожилой человек → «Подключить браслет или часы» → разрешите доступ к шагам, пульсу, активности.
4. «Вести по GPS» — телефон попросит доступ к местоположению; после разрешения родственник видит точную позицию.

## Требования Google (для публикации в Play, не для теста)
Приложения, читающие данные о здоровье, Google публикует только с **политикой конфиденциальности**. Черновик — в файле `POLITIKA_SOUKROMI.md`, его нужно будет разместить по ссылке в интернете. Для установки `.apk` на свой телефон это не требуется — только для магазина.

## Для iPhone
Нужен Mac и аккаунт Apple Developer (99 $/год) — сделаем отдельно; плагин здоровья уже поддерживает Apple Health.
