# Near — настройка онлайн-режима (для теста вдвоём)

Онлайн-режим даёт настоящую **регистрацию, вход под разными аккаунтами** и **синхронизацию между телефонами** — родственник видит реальное местоположение, шаги и статус пожилого человека. Работает на бесплатном сервисе Google Firebase, свой сервер не нужен.

Нужно один раз создать бесплатный проект Firebase (~10 минут) и вставить его код в приложение. Программировать не нужно — только скопировать и вставить.

## Шаг 1. Создать проект Firebase

1. Откройте **console.firebase.google.com**, войдите под Google-аккаунтом.
2. Нажмите **«Create a project»** (Создать проект). Придумайте название, например `near-test`. Google Analytics можно **выключить**. Дождитесь создания.

## Шаг 2. Включить вход по почте

1. Слева в меню: **Build → Authentication → Get started**.
2. Вкладка **Sign-in method** → выберите **Email/Password** → включите (Enable) → Save.

## Шаг 3. Создать базу данных

1. Слева: **Build → Firestore Database → Create database**.
2. Выберите регион (например, **europe-west**) → режим оставьте **Production mode** (рабочий). Нажмите Enable.

## Шаг 3б. Вставить правила безопасности (важно!)

Это защищает данные пожилого человека: их видит только он сам и одобренный им родственник. Без этого шага онлайн работать не будет.

1. В разделе **Firestore Database** откройте вкладку **Rules** (Правила).
2. Выделите весь текст в поле и удалите.
3. Откройте файл **PRAVIDLA_BEZPECNOSTI.txt** (я приложила его рядом с этим), скопируйте **всё** его содержимое и вставьте в поле.
4. Нажмите **Publish** (Опубликовать).

> В отличие от тестового режима, эти правила **не истекают через 30 дней** и закрывают данные от посторонних.

## Шаг 4. Получить код (config) приложения

1. Слева вверху нажмите на шестерёнку ⚙️ → **Project settings**.
2. Прокрутите вниз до **Your apps** → нажмите значок **</>** (Web).
3. Придумайте название (например `near`) → **Register app**.
4. Появится блок с текстом вида:

   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "near-test.firebaseapp.com",
     projectId: "near-test",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "1:...:web:..."
   };
   ```

5. **Скопируйте весь блок в фигурных скобках** `{ ... }` (можно вместе со словом `const firebaseConfig =` — приложение разберётся).

## Шаг 5. Вставить код в приложение

1. Откройте Near на телефоне → на экране входа нажмите **«Настроить онлайн-режим»**.
2. Вставьте скопированный конфиг в поле → **«Сохранить и включить»**.
3. Закройте и снова откройте приложение. На экране входа появятся кнопки **«Войти»** и **«Регистрация»**.

Важно: этот шаг нужно сделать на **каждом** телефоне (вашем и подруги) — конфиг одинаковый для всех.

## Шаг 6. Тест вдвоём

1. Вы: **Регистрация** → выберите роль **Пожилой человек** → почта, пароль, имя. Откройте «Подключение и устройства» — там ваш **код**.
2. Подруга (на своём телефоне): **Регистрация** → роль **Родственник** → своя почта/пароль. Затем «Связь» → «Подключиться по коду» → введите **ваш код**.
3. Вы у себя подтверждаете заявку (в «Подключение и устройства»).
4. Готово: подруга на «Карте» и в «Обзоре» видит ваше реальное местоположение, шаги и статус. Нажмите у себя «Вести по GPS», «Со мной всё хорошо» — она увидит изменения.
